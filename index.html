HELP

사용 설명서

① 처음 사용할 때

앱을 처음 실행하면 샘플 데이터가 기본으로 표시돼. 샘플은 기능 확인용이며 실제 근무표가 아니야.

실제 사용 시에는 최신 근무표 Excel(.xlsx)을 직접 업로드해서 사용해. 실제 근무표 파일은 앱에 미리 포함되어 있지 않아.

② 근무표 저장 · 사용

근무표 버튼에서 ＋ 근무표 저장을 누르면 Excel을 불러와 미리보기를 열어. 연월·시트·날짜 행·이름 열과 선임 그룹 인원을 확인하고, 원본 대조 확인란을 선택한 뒤 저장해. 저장만 했다고 바로 현재 화면에 적용되지는 않아.

저장된 목록에서 사용을 눌러야 해당 월 근무표가 현재 적용돼. 사용 중 표시가 현재 적용된 근무표야.

여러 월의 근무표를 동시에 보관할 수 있어. 다른 월을 저장하거나 사용해도 나머지 월의 저장 데이터에는 영향을 주지 않아.

같은 월의 근무표를 다시 저장하면 기존 파일을 교체할지 확인해. 교체하면 해당 근무표의 수동 수정사항과 인원 추가·제외·프로필 수정도 함께 초기화돼.

삭제하면 해당 근무표와 연결된 수동 수정사항이 함께 삭제돼. 현재 사용 중인 근무표를 삭제하면 샘플 데이터로 전환돼.

③ 날짜 선택

상단 날짜를 누르면 달력이 열려. ‹ / ›로 월을 이동하고 날짜를 선택할 수 있어. 앞·뒤 달에 표시된 날짜도 바로 선택할 수 있어.

오늘 버튼은 현재 날짜와 현재 시간대의 듀티로 돌아가. 달력은 ESC 또는 바깥 영역을 눌러 닫을 수 있어.

근무표에 선택한 날짜 열이 없으면 인원을 확인 불가로 표시해. 해당 날짜가 포함된 파일을 다시 불러와야 배치를 수정하거나 인쇄할 수 있어.

④ 듀티 선택

D 07:30–15:00 · E 15:00–22:00 · N 22:00–다음 날 07:30 기준으로 동작해.

직접 D/E/N을 누르거나 이전 듀티 / 다음 듀티 / 다음 날 D로 이동할 수 있어. N 근무는 시작일 기준으로 표시돼.

⑤ 자동 배치

현재 선택한 날짜와 듀티의 근무자를 선임순으로 정렬한 뒤 MICU 기본 규칙에 따라 배치해.

1번째 선임 → 통보연락반
2·3번째 선임 → 소화반
4번째 이하 → 대피유도반

원본 근무표에는 간호사만 포함되어 있어. 인원 관리에서 사용자가 추가한 사원·의사는 대피유도반에 함께 배치해. 실제 자료가 확보되면 이 규칙은 실제 대피배치판과 함께 다시 검토할 수 있어.

⑥ 수동 수정

✎ 버튼으로 수정 모드에 들어가면 배치된 사람을 직접 변경할 수 있어. 여러 명이 한 역할에 있으면 각 사람을 개별적으로 수정할 수 있어.

사람 사이의 · 표시는 단순한 구분자야. 배치 데이터에는 포함되지 않아.

자동 배치와 수동 수정은 별도로 관리돼. 사용자가 수정한 값은 자동 배치보다 항상 우선해서 최종 화면에 표시돼.

입력 중에는 전체 화면을 다시 그리지 않고, 수정사항 저장을 눌렀을 때 수동 override로 확정해.

⑦ 수정사항 저장 · 초기화

저장 중 → 트랜잭션 완료 → 다시 읽어 내용 일치 확인을 모두 통과해야 성공 메시지를 표시해. 실패하면 입력을 유지하니 다시 시도해줘. 저장 상태와 원인은 화면의 저장 상태 영역에서 확인할 수 있어.

수정사항 저장을 누르면 현재 수동 수정이 브라우저 저장소에 저장돼. 따라서 새로고침하거나 브라우저를 다시 열어도 저장된 수정사항을 복원할 수 있어.

각 역할의 ↺ 초기화는 그 역할의 수동 수정만 제거하고 다른 역할의 수정은 유지해.

수정 중 화면을 이동하려고 하면 저장하지 않은 변경사항이 있을 경우 확인창이 나타나.

인원 추가 · 수정 · 삭제

인원 관리에서 이름·직종·선임 그룹을 입력하고 인원을 추가할 수 있어. 추가·삭제는 선택한 날짜·듀티에만 적용돼. 기존 인원의 이름·직종·그룹 수정은 해당 근무표 전체에 적용돼.

이미 배치된 사람을 삭제하면 확인 후 배정도 해제돼. 원본 근무표는 보존되며 제외한 원본 인원은 복원할 수 있어. 변경사항 저장을 눌러야 확정돼. 같은 이름도 내부 ID로 구분해.

⑧ 저장 데이터의 범위

근무표와 수동 수정사항은 현재 사용하는 브라우저의 로컬 저장소에 보관돼. 인터넷 서버에 자동으로 전송하는 기능은 현재 없어.

앱 배포 파일에는 실제 운영 근무표를 넣지 않고, 개발·테스트용 샘플 데이터만 포함하는 것을 원칙으로 해.

따라서 다른 컴퓨터나 다른 브라우저에서는 최신 근무표를 업로드하거나 전체 백업 파일을 복원할 수 있어. 자동 공유는 되지 않아.

⑨ 인쇄

🖨 버튼을 누르면 현재 선택한 날짜·듀티의 최종 배치를 인쇄할 수 있어. 저장된 수동 수정사항이 있다면 수정된 최종 배치가 인쇄돼.

인쇄 전에는 날짜, 듀티, 현재 사용 중인 근무표를 확인하는 것을 권장해.

⑩ 문제가 생겼을 때

근무표가 안 보이면: 해당 월의 근무표가 실제로 사용 상태인지 확인해.

사람이 없으면: 선택한 날짜/듀티에 D/E/N으로 인정되는 근무자가 있는지 확인해. OF, V, C, PE 등 비근무 코드는 근무자로 처리하지 않아.

수동 수정이 안 보이면: 수정 모드에서 수정사항 저장을 눌렀는지 확인해.

새로운 실제 근무표를 넣으려면: 최신 Excel을 다시 저장하고, 목록에서 사용을 눌러 적용해.

⑪ 웹사이트로 사용할 때 알아둘 점

프로그램은 안내받은 인터넷 주소(URL)를 열어서 사용해. 프로그램 파일이나 HTML을 직접 열 필요 없이, 웹브라우저에서 주소를 열면 돼.

저장한 근무표와 배치 내용은 사용한 컴퓨터의 해당 브라우저에 저장돼. 인터넷에 있는 하나의 공용 저장공간에 저장하는 방식은 아니야.

같은 컴퓨터에서 같은 브라우저를 계속 사용하면 브라우저를 닫았다가 다시 열어도 저장한 내용을 다시 사용할 수 있어.

다른 컴퓨터나 다른 브라우저에서는 기존 데이터가 자동으로 보이지 않아. 같은 URL을 열더라도 저장공간이 각각 따로 있기 때문이야.

컴퓨터에 문제가 생기거나 브라우저의 사이트 데이터가 삭제되면 저장한 내용이 사라질 수 있어. 전체 백업 내려받기로 근무표·인원 변경·수동 배치·이력을 함께 보관해.

여러 사람이 여러 컴퓨터에서 하나의 근무표를 함께 조회하거나 수정해야 하는 경우에는 현재 버전만으로는 부족해. 나중에 별도의 서버와 데이터베이스를 연결하는 개발이 필요해.

⑫ 수정 이력과 Excel 내려받기

수정 이력에서 근무표 등록·삭제, 인원·이름·역할 변경, 자동배치·수동 수정, 초기화와 저장 성공·실패를 최신순으로 확인해. v0.7.2 이후의 저장부터 기록하며, 저장하지 않은 입력과 메뉴 열기 등은 기록하지 않아.

시작일·종료일, 작업, 환경으로 필터하고 날짜별·환경별로 모아볼 수 있어. 현재 결과 내려받기는 필터에 맞는 모든 이력을, 전체 이력 내려받기는 전체를 Excel로 내려받아. 화면에 아직 더 보기를 하지 않은 이력도 포함돼.

각 기록에는 변경 전후, 결과, 앱 버전, 기기 유형·OS·브라우저 종류를 남겨. 이 정보는 브라우저가 제공하는 값으로 추정하며, 개인·기기를 식별하는 ID를 수집하지 않아. 이력 ID는 사건을 구분하기 위한 값이야.

이력은 운영 데이터와 별도 영역에 보관돼. 근무표 삭제·교체 후에도 남지만, 기기 간 공유되지 않고 사이트 데이터 삭제 시 함께 사라져. 이전 변경을 복구하는 백업이나 서버 감사로그는 아니야.

이력 저장 대기 알림이 보이면 실제 데이터 저장 결과와 별도로 이력 저장을 재시도해줘. 대기 이력은 현재 창에만 있으므로 창을 닫기 전에 재시도하거나 Excel로 보관해. 저장 실패는 쓰기 또는 저장 후 확인 실패를 뜻하며, 실제 데이터가 일부 저장된 경우도 있어.

⑬ 전체 데이터 백업 · 복원

전체 백업 · 복원 → 전체 백업 내려받기로 이 브라우저의 근무표, 인원 변경, 수동 배치, 선택 상태, 수정 이력을 JSON 파일 하나에 보관해. 앱 ZIP이나 이력 Excel과는 다른 파일이야.

복원할 JSON을 선택하면 파일 손상·형식·인원 연결 정보를 먼저 검사해. 미리보기를 확인하고 복원 전 현재 데이터 백업을 내려받아 보관한 다음 확인란을 선택해야 전체 복원을 실행할 수 있어.

전체 복원은 현재 데이터를 합치는 것이 아니라 수정 이력까지 백업 시점으로 교체해. 복원 성공 후 해당 작업을 새 이력으로 남겨. 일반 근무표 삭제·교체는 이전처럼 수정 이력을 유지해.

다른 탭을 닫고 복원하고, 사용 중이던 탭은 새로고침해. 복원 후 다시 읽기 확인에 실패했다는 안내가 나오면 복원을 반복하기 전에 새로고침해 내용을 확인해. 복원 전 백업은 계속 보관해.

백업 파일에는 이름·근무 정보가 들어 있고 암호화되지 않아. 내려받기는 브라우저 다운로드 목록에서 확인해. 파일 크기는 20MB까지 지원해.
