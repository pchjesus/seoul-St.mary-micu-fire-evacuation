배치 규칙

현재 확인된 MICU 화재대피 반 편성을 기본 규칙으로 적용해. 이 화면에서는 규칙을 임의로 바꾸지 않고, 실제 병원 자료가 추가되면 다음 버전에서 규칙을 확장하는 구조로 유지해.

② 소화반차선임 + 3번째 선임

HELP

사용 설명서

① 처음 사용할 때

앱을 처음 실행하면 샘플 데이터가 기본으로 표시돼. 샘플은 기능 확인용이며 실제 근무표가 아니야.

실제 사용 시에는 최신 근무표 Excel(.xlsx)을 직접 업로드해서 사용해. 실제 근무표 파일은 앱에 미리 포함되어 있지 않아.

② 근무표 저장 · 사용

근무표 버튼에서 ＋ 근무표 저장을 누르면 Excel을 불러와 브라우저에 저장해. 저장만 했다고 바로 현재 화면에 적용되지는 않아.

저장된 목록에서 사용을 눌러야 해당 월 근무표가 현재 적용돼. 사용 중 표시가 현재 적용된 근무표야.

여러 월의 근무표를 동시에 보관할 수 있어. 다른 월을 저장하거나 사용해도 나머지 월의 저장 데이터에는 영향을 주지 않아.

같은 월의 근무표를 다시 저장하면 기존 파일을 교체할지 확인해. 교체하면 기존 그 월의 수동 수정사항도 함께 초기화돼.

삭제하면 해당 근무표와 연결된 수동 수정사항이 함께 삭제돼. 현재 사용 중인 근무표를 삭제하면 샘플 데이터로 전환돼.

③ 날짜 선택

상단 날짜를 누르면 달력이 열려. ‹ / ›로 월을 이동하고 날짜를 선택할 수 있어. 앞·뒤 달에 표시된 날짜도 바로 선택할 수 있어.

오늘 버튼은 현재 날짜와 현재 시간대의 듀티로 돌아가. 달력은 ESC 또는 바깥 영역을 눌러 닫을 수 있어.

④ 듀티 선택

D 07:30–15:00 · E 15:00–22:00 · N 22:00–다음 날 07:30 기준으로 동작해.

직접 D/E/N을 누르거나 이전 듀티 / 다음 듀티 / 다음 날 D로 이동할 수 있어. N 근무는 시작일 기준으로 표시돼.

⑤ 자동 배치

현재 선택한 날짜와 듀티의 근무자를 선임순으로 정렬한 뒤 MICU 기본 규칙에 따라 배치해.

1번째 선임 → 통보연락반
2·3번째 선임 → 소화반
4번째 이하 → 대피유도반

현재 데이터에는 간호사만 포함되어 있으므로 다른 직종을 임의로 만들어 배치하지 않아. 실제 자료가 확보되면 이 규칙은 실제 대피배치판과 함께 다시 검토할 수 있어.

⑥ 수동 수정

✎ 버튼으로 수정 모드에 들어가면 배치된 사람을 직접 변경할 수 있어. 여러 명이 한 역할에 있으면 각 사람을 개별적으로 수정할 수 있어.

사람 사이의 · 표시는 단순한 구분자야. 배치 데이터에는 포함되지 않아.

자동 배치와 수동 수정은 별도로 관리돼. 사용자가 수정한 값은 자동 배치보다 항상 우선해서 최종 화면에 표시돼.

입력 중에는 전체 화면을 다시 그리지 않고, 수정사항 저장을 눌렀을 때 수동 override로 확정해.

⑦ 수정사항 저장 · 초기화

수정사항 저장을 누르면 현재 수동 수정이 브라우저 저장소에 저장돼. 따라서 새로고침하거나 브라우저를 다시 열어도 저장된 수정사항을 복원할 수 있어.

각 역할의 ↺ 초기화는 그 역할의 수동 수정만 제거하고 다른 역할의 수정은 유지해.

수정 중 화면을 이동하려고 하면 저장하지 않은 변경사항이 있을 경우 확인창이 나타나.

⑧ 저장 데이터의 범위

근무표와 수동 수정사항은 현재 사용하는 브라우저의 로컬 저장소에 보관돼. 인터넷 서버에 자동으로 전송하는 기능은 현재 없어.

앱 배포 파일에는 실제 운영 근무표를 넣지 않고, 개발·테스트용 샘플 데이터만 포함하는 것을 원칙으로 해.

따라서 다른 컴퓨터나 다른 브라우저에서 사용하려면 그 환경에서 최신 근무표를 다시 업로드해야 해.

⑨ 인쇄

🖨 버튼을 누르면 현재 선택한 날짜·듀티의 최종 배치를 인쇄할 수 있어. 저장된 수동 수정사항이 있다면 수정된 최종 배치가 인쇄돼.

인쇄 전에는 날짜, 듀티, 현재 사용 중인 근무표를 확인하는 것을 권장해.

⑩ 문제가 생겼을 때

근무표가 안 보이면: 해당 월의 근무표가 실제로 사용 상태인지 확인해.

사람이 없으면: 선택한 날짜/듀티에 D/E/N으로 인정되는 근무자가 있는지 확인해. OF, V, C, PE 등 비근무 코드는 근무자로 처리하지 않아.

수동 수정이 안 보이면: 수정 모드에서 수정사항 저장을 눌렀는지 확인해.

새로운 실제 근무표를 넣으려면: 최신 Excel을 다시 저장하고, 목록에서 사용을 눌러 적용해.
